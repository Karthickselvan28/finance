# Tech Context: FastAPI and React/Vite

The backend of this application is built with **FastAPI**, a modern, fast (high-performance) web framework for building APIs with Python. The frontend is a **React** application built with **Vite**, a build tool that aims to provide a faster and leaner development experience for modern web projects.

- **Backend:** FastAPI, Python, Uvicorn
- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Package Managers:** pip (backend), npm (frontend)
